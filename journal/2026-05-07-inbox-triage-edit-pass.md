## Summary

Long session in the philoserf/notes Obsidian vault. Three inbox-triage batches (30 notes routed), 10 draft copy-edit passes via the `/editor` skill, structural rewrite on one draft, two GitHub issues filed, and a filler-word audit across 301 drafts.

## Key Findings

- **Routing heuristic correction**: Paragraph-form essays (3–7 paragraphs) belong in `Drafts/`, not `Reference/`, even when written in third-person without first-person voice. The "third-person, explanatory tone" Reference signal mis-routes the user's own developed thinking. See [[2026-05-07-essay-shape-is-drafts]].
- **Filler-word corpus pattern**: `fundamental` (176), `actually` (93), `simultaneously` (68), `genuinely` (60), `simply` (59), `fully` (55) recur across the Drafts/ corpus. See [[2026-05-07-philoserf-filler-words]].
- **Surface structural advice prominently**: When `/editor` produces structural recommendations (cut paragraphs, reorganize), they need to be visually separated from line-edit flags, not buried after them. See [[2026-05-07-editor-output-structure]].
- **Calibrate via artifact, not description**: When uncertain about register or shape, sample the user's published work directly. Abstract destination descriptions ("Reference is for things consulted but not written") miss the mark; concrete examples don't.
