When a prose-history project compiles from multiple authoritative sources that occasionally disagree, document each contradiction rather than silently resolving it.

## Pattern

A dedicated **Note section** (in the Clement project, `timeline.md`'s Note section) holds permanent records. Each entry:

1. Bold heading naming the contradiction.
2. Quote both sides with file:page citations.
3. State which side prevails as canon for the prose project.
4. Explain why (precedence rule applied).

## Precedence rule (Clement)

When sources disagree:

1. Subsector sourcebook beats theme-focused book.
2. Later edition (3e) beats earlier (2.0).
3. Detailed multi-sentence account beats compressed one-sentence reference.

## Why permanent

Contradictions don't go away — they recur each time someone re-reads the sources. The Note section saves future-you from re-litigating decisions already made. Joins the prose project's documented canon record alongside the chapter prose itself.
