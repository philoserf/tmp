When presenting options, lead with the more durable/principled choice. The user said "I have a hard time picking 1" when option 1 was the quick-and-dirty approach and option 2 was more maintainable.

## Why

The user values durability and correctness over expediency. Presenting the expedient option first frames it as the default, which doesn't match preferences.

## How to apply

Order options with the more principled choice first. If the expedient option is genuinely better for the situation, explain why concretely.
